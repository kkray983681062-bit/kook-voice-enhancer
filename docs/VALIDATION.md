# 验证范围

记录日期：2026-11-07。测试环境为 Windows x64、KOOK 0.112.0。

## 当前发布版 1.1.3

- 通过 `celt_test.c` 直接编译发布代码中的同一 CELT 控制函数，在独立进程内使用真实引擎与合成信号；没有向语音频道发送合成音频。
- 原始单声道目标 300：平均 260.272 kbps，内部回读 260,000 bps。
- 启用修复的选中单声道：平均 300.272 kbps，内部回读 300,000 bps。
- 未选中的另一个单声道：仍为 260.272 kbps；关闭内部调整后，原编码器恢复为 260.272 kbps。
- 选中双声道目标 320：平均 320.267 kbps，内部回读 320,000 bps。
- 各组均为 0 编码错误，VBR 和 DTX 保持启用。
- 真实频道测试 20 秒、336 帧、0 编码错误，上层 / Opus 目标均为 300,000 bps；恢复上层及 Opus 原值 32,000 bps 通过。该次网络保护选择混合编码，未以它证明持续输出 300。
- 桌面 EXE 1.1.3 已应用并保持单声道 300；用户在新版实际应用后确认“声音正常”，并要求更新发布包。
- 真实 0.110.0 / 0.112.0 引擎均唯一识别 CELT 控制函数及动态字段偏移，CELT 多匹配、260,000 限制语义被改变时均拒绝控制。

## 历史发布版 1.1.2

- 真实 0.110.0 / 0.112.0 引擎文件：唯一识别 Opus、上下层编码函数和上层码率函数；函数地址不同，关键偏移从指令提取。
- 多个匹配及码率语义被改变时拒绝控制。旧版仅做文件识别测试，没有启动旧客户端通话。
- 最终原生单声道测试：12 秒、202 帧、0 编码错误，上层和 Opus 目标均为 300,000 bps，实际分配容量 4560 字节；一秒峰值 264.560 kbps。恢复两层各 32,000 bps 成功。
- 桌面 GUI：单声道目标 300，30 秒曲线峰值 268.77 kbps。用户确认声音连续、无明显失真，随后确认自行测试无问题。
- 另一轮保持测试主动请求 SDK 下调至 64 kbps，上层仍保持 300 kbps；测试后已修正并复测状态回读时序。
- 曲线的时间 / 字节换算、非整秒间隔、断流、重新连接和 30 秒过期检查通过；自动重连条件及重复连接保护检查通过。
- 朋友的 10007：将 KOOK 音频子系统从“标准”切换为“先进”，彻底退出重开后，用户确认连接成功。

## 限制

- 300 / 320 是目标码率，不承诺 VBR 的每一秒输出都等于目标。
- 测量的是本机编码输出，不是服务器转发或对端接收；没有宣称修改服务器权益或限制。
- 本轮没有独立完成最终原生版双声道 320 的重新计量；双声道预设已有较早版本的重连与回读验证。
- 用户关闭保持时，KOOK 可以继续自行调整码率；关闭增强器后也不再保持。
- 未来版本的引擎或 ABI 变化可能需要适配，不能承诺所有更新均兼容。
- 单独运行同一编码器的合成信号测试属于离线验证，不能代替真实通话或对端验收。

## 269 / 280 kbps 补充调查

同一 KOOK 0.112.0 编码器，在独立进程内编码合成信号，没有向频道发送测试音频。每组 100 帧，编码错误均为 0：

| 声道 / 请求目标 | 帧长 | 模式 | 平均编码输出 |
| --- | --- | --- | --- |
| 单声道 / 300 | 60 ms | VBR | 260.288 kbps |
| 单声道 / 300 | 20 ms | VBR | 260.400 kbps |
| 单声道 / 300 | 20 ms | CBR | 300.000 kbps |
| 双声道 / 320 | 60 ms | VBR | 320.347 kbps |
| 双声道 / 320 | 20 ms | CBR | 320.000 kbps |

静态检查确认当前引擎的 CELT 码率控制包含 `260000 × 声道数` 的目标截断，与 [Opus v1.3.1 CELT 源码](https://github.com/xiph/opus/blob/v1.3.1/celt/celt_encoder.c#L2333-L2339) 的行为一致。VBR 输出允许围绕目标变化；这个内部目标不是单包或一秒峰值的硬上限。用户随后反馈实际超过 280 kbps，并确认声音正常、要求发布当前稳定版本。

1.1.2 没有修改 CELT 内部目标。1.1.3 已处理这个截断，但仍保留帧长、VBR、DTX 和丢包保护。上述离线 CBR 300 与双声道平均 320 的结果不等于真实频道已完成相同验证。
